## 0.7.0 (2026-08-05)

### Tag Query Performance
- Rewrote `listTags` SQL to single-pass window function (`ROW_NUMBER() OVER PARTITION BY tag ORDER BY updated_at`) instead of per-tag subqueries
- Added `idx_media_updated_at` index for faster tag aggregation

### Thumbnail Generation
- Concurrency limiter (max 3 parallel ffmpeg processes) prevents thumbnail request storms from spawning dozens of ffmpeg instances
- Switched to async `fs/promises` in thumbnail handler (non-blocking stat/access)
- Better handling of missing source files (async access check before spawn)

### Tag Page Pagination
- Tag page now uses server-side pagination (`fetchMedia({ limit, offset })`) instead of loading all media client-side
- Removed client-side page cache in favor of server pagination

### Lazy Thumbnail Loading
- `MediaCard` and `TagCard` use IntersectionObserver to defer thumbnail requests until the card is within 200px of the viewport
- Reduces server load on large grids significantly

### Offline Tag Search
- IndexedDB queries now support `search` and `tag` filters, mirroring server-side filter logic
- Tags list cached optimistically via `getLastTags()` — shows stale data immediately while fetching fresh

### Release Notes
- Added releasing instructions section to AGENTS.md

## Session 3 Updates

### Improved Folder Discovery

The find-folder endpoint now:
- Searches deeper in user directories (up to 6 levels in Pictures/Videos)
- Checks more drive letters (D: through H:)
- Uses per-path depth limits for faster searching
- Skips more system folders (Windows, Program Files, etc.)

### Manual Path Input (Cross-Device Fallback)

When the server can't automatically locate a folder:
1. A modal prompts for the full path (e.g., `D:\Photos\SFW`)
2. User can paste the path from File Explorer
3. Server-side scan enables cross-device access
4. "Skip (Local Only)" option for device-local access only

## 0.7.2 (2026-08-21)

### Server
- **`likeMedia`** now returns `likedCount` (total of liked items) on the first like, so the client can update sidebar counts without an extra request. Re-likes omit it.
- **`updateTags`** now returns `tagCount` (distinct tags across visible media) for the same reason.
- **`listMedia`** supports `sort=none` (id ASC) and `sort=likes` options.
- **`.ts` detection** — new `src/mediaFile.js` content-sniffs `.ts` files (valid UTF-8 text vs MPEG-TS with 0x47 sync bytes), so TypeScript source files are no longer scanned or kept as video records. Scan also removes stale `.ts` records that were mis-detected as video (safeguarded to never drop records with likes/tags/transcoded output).
- **Folder previews** now use the latest-added media (`MAX(id)`) instead of the oldest; thumbnail propagation only fills a parent when the child preview is newer.
- **Migration ordering** — DB migrations now run before index creation, fixing a startup crash on databases missing migrated columns.
- **CORS** — added `PATCH` to allowed methods.
- **Folder picker dialog** uses an owner window + `windowsHide` so it appears on top without flashing a console.
- **New `POST /media/:id/open`** endpoint opens the media file in the OS default player (falls back to the original path when the transcoded output is missing; reports non-zero exits as errors).

### Shared
- New `TOAST_PROGRESS` action; new `config.defaults.js` client-safe port defaults; new `mediaOpen`, `openFolder`, `mediaUpload` route constants.

### Web
- Removed the clickable like button from media cards — like counts now display as a static badge only when non-zero.
- Removed the pencil rename icon from folder cards; rename now triggers on double-click of the folder name.
- New `dev:fresh` script (installs deps, then starts web + server).

### CI
- New `test.yml` workflow runs server tests on all PRs and master; `build.yml` now runs tests before building.
- Fixed a stale scan test (asserted probe-job creation that no longer exists; now asserts the actual image-ready/video-pending status contract).

### Docs
- README updated: Node 22+/pnpm 10+, correct ports (7838), browse-for-folder flow, project structure, full keyboard shortcuts.
